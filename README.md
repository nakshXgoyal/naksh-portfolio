# Naksh — Portfolio

## Setup

1. Unzip this folder and open a terminal inside it.
2. Run `npm install`
3. Run `npm run dev`
4. Open the URL shown in the terminal (usually http://localhost:5173)

## Before your interview, edit these files

- `src/components/Hero.jsx` — your name, tagline, bio in the terminal output
- `src/components/Projects.jsx` — swap in your real projects and links
- `src/components/Skills.jsx` — your actual tech stack
- `src/components/Timeline.jsx` — your real work/education history
- `src/components/Contact.jsx` — your email, LinkedIn, GitHub links
- Add a `resume.pdf` file to the `public/` folder so the "Download résumé" button works

## Deploy for free

- Push this folder to a GitHub repo
- Go to vercel.com or netlify.com, import the repo, deploy (auto-detects Vite)
